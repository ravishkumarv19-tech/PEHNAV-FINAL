# 🎬 Google Veo Video Drop Zone

Drop your exported Google Veo video file (`.mp4`, `.webm`, or `.mov`) into this folder:
`pehnav/public/hero-frames/raw-video/`

Then tell the assistant or run:
```bash
python extract_veo_video.py
```
This will automatically extract 120 high-definition WebP frames and sync the hero scroll engine.
